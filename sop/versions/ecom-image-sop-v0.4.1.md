## 1. 先判断路径：新款还是旧品翻单？

不是所有需求都从种子图开始，合格的旧图本身可以成为高价值资产。
<a id="route"></a>

### 新款 · 标准生产路径

**PATH A / STANDARD** · 不能跳过 Gate A

适用：新上市款、首次为该款建立真人穿着图、现有图片不足以确认版型和人物形象。

1. 准备静物图、模特与身材比例
2. 生成柔光纯色背景全身种子图
3. 种子图局部重修，确保商品准确
4. 进入场景、精修并确认正式母图
5. 姿势裂变、逐张精修、交付

### 旧品 · 快速翻单路径

**PATH B / FAST TRACK** · 可跳过初建种子图

适用：已有可信模特图，服装与商品信息仍然正确，希望快速翻新场景或追加更多 pose。

1. 复核旧图、旧款与当次商品是否一致
2. 视需要抠出干净主体并局部修正
3. 直接用旧图进入母图确认环节
4. 按目标场景或原场景扩展裂变
5. 逐张精修、交付

> **旧品快速路径的入口门槛：**旧图不是“有就能用”。如果同货号发生版型、面料、颜色、印花或工艺调整，必须先纠正不一致项；不得让过时商品图成为新成片的真实商品基准。

### 从判断到交付：总流程

```text
START｜核对需求、产品状态、渠道与可用素材
    ├─ 新款：商品静物＋模特＋比例 → 种子图 → 商品与人物校验（Gate A）
    └─ 旧品：复核可信旧图 → 必要局部修正或抠图 → 跳过新种子图
                        ↓
MERGE｜干净主体＋目标场景＋商品细节参考 → 全身基础站立图
                        ↓
Gate B｜修色、光影与瑕疵 → 锁定正式场景母图
                        ↓
SPLIT｜小变化：母图＋文字；大变化：母图＋白模＋文字
                        ↓
Gate C｜逐张修色、面部、印花及工艺 → 完稿验收
                        ↓
OUTPUT｜渠道适配、命名、导出、归档
```


## 2. 三个核心资产：种子图、场景母图、裂变图

明确每张图的职责，避免“最新生成的图”自动变成新的参考标准。
<a id="assets"></a>

### 种子图（ASSET 01 / SEED）

柔光纯色背景、全身站姿，用于建立模特身份、身材比例、商品款式及基础穿着关系。

**判断：**商品与人是否正确？不承担复杂场景氛围任务。

### 场景母图（ASSET 02 / MASTER）

主体进入正式场景并经过校色、瑕疵修复和光影融合的全身基础站立图。

**判断：**系列拍摄空间、色调、人物与商品基准是否稳定？

### 裂变图（ASSET 03 / DERIVED）

基于正式母图产生的不同姿势、景别、机位和构图，每张都须独立审核及精修。

**判断：**允许摄影关系变化，但商品真实细节和身份不漂移。

### 素材净化 / 提供白底抠图主体

人物或商品融合入新场景时，原图中的家具、绿植、墙面、杂物、其他人物和背景光影可能成为无关信息。**优先尝试将主体单独整理成干净的白底抠图参考或透明素材**，再与目标背景、商品细节参考共同输入。

**白底抠图图**  
适合作为干净视觉参考，减少旧场景污染；它本身仍然有白色像素，不是真透明文件。

**真实透明 PNG**  
适合实际分层、合成及需要 Alpha 的流程；生成结果应检查 RGBA / Alpha，不能凭 PNG 扩展名判断。

如果原图的接地阴影、家具接触和人物与空间关系很有价值，可同时提供原图作为空间参考；净化素材是优先手段，不是每张图强制抠图。

## 3. 八阶段生产 SOP

每阶段包含输入、具体操作、输出以及失败时的回退位置。
<a id="sop"></a>

### 01｜任务与基础素材准备

**阶段标签：**新款 / 旧品共用

先确认商品事实和目标用途，不在生成后才补找参考。

**输入 INPUT**

- 商品静物图：整体、颜色、印花、领口/袖口/裤脚等工艺
- 模特身份或形象参考、目标身材比例
- 目标场景图或场景方向
- 使用用途、需要的张数/景别/比例

**操作 ACTION**

1. 核对同货号、同色、同款、同季的商品状态。
2. 明确哪张图负责人物、哪张负责商品、哪张负责场景。
3. 判断是否有资格走旧品快线；确认有无可用母图。
4. 有需要时抠出干净白底/透明主体，去掉不相关背景信息。

**输出 / 返工**

**输出：**素材包＋图片职责记录＋本单生产路径。

**不通过：**缺商品关键工艺、颜色不确定、参考图职责冲突 → 先补参考，不急于生图。

**阶段结论：**知道这次“谁是什么、穿什么、在哪里拍、要出几张”。

### 02｜生成全身种子图

**阶段标签：**新款必做

用简单光场确认人物与商品；旧品合格图可跳过。

**输入 INPUT**

- 静物商品及细节参考
- 模特身份参考、体型比例要求
- 简单纯色背景

**操作 ACTION**

1. 优先生成柔光纯色背景、全身基础站立 pose。
2. 控制人脸/发型、身材、头颈、手脚比例与服装穿着状态。
3. 保证头顶、衣摆、裤脚和鞋底可检查，不借复杂道具遮挡缺陷。

**输出 / 返工**

**输出：**可用于核实人物和商品的初始种子图。

**不通过：**整体人物/服装严重失真 → 重生成；局部印花或工艺错误 → 转 03 局部修正。

**阶段结论：**把“人穿这件衣服”建立成易于审核的视觉基准。

### 03｜种子图局部重修 → Gate A

**阶段标签：**种子验收

先解决商品真实度，再允许进入复杂场景。

**输入 INPUT**

- 初始种子图
- 商品原始静物/局部工艺图
- 面部或比例参考（如有）

**操作 ACTION**

1. 针对印花、领口、拼缝、裤脚和颜色做局部修改。
2. 检查模特身份、头身比、五官、四肢和鞋底完整性。
3. 对正确区域设“保留”，避免局部修复影响整体款式。

**输出 / 返工**

**输出：**合格种子图，并保留原始商品细节参考。

**不通过：**衣服整体改款/人物明显不一致 → 退回 02；仅局部问题 → 继续 03。

**Gate A：**人物与商品正确后，才进入正式场景。

### 04｜融合场景：形成全身基础站立图

**阶段标签：**场景建立

这是从产品基准走向正式商业摄影氛围的阶段。

**输入 INPUT**

- 合格种子图；旧品则用复核后的旧图
- 目标场景背景图
- 必要时白底抠图/透明主体
- 细节参考图，继续保护商品

**操作 ACTION**

1. 按图源职责融合人物、商品、目标背景；可借助现有 Skill 表达保留边界。
2. 优先建立全身自然基础站姿，暂不追求多姿势。
3. 检查主体大小、机位、地平线、透视、受光、接地阴影与环境反射。
4. 仅借场景时，不把背景图自带人物与道具误当作指定主体。

**输出 / 返工**

**输出：**正式场景基础站立初稿。

**不通过：**脸或商品漂移 → 回查 03/旧图基准；机位或视差错 → 重新建立 04 场景关系。

**阶段结论：**人物已经“真的站在”目标场景里，而不是简单贴入。

### 05｜精修并锁定正式场景母图 → Gate B

**阶段标签：**母图验收

母图是整组裂变的共同标准，必须有版本意识。

**输入 INPUT**

- 阶段 04 场景初稿
- 种子图、人物参考、商品参考
- 原场景或调性参考

**操作 ACTION**

1. 优先修明显偏色、肤色异常、背景脏斑及人物贴纸感。
2. 检查商品款式、印花、工艺在场景融合后有没有再次变化。
3. 统一主光、阴影、环境色与真实摄影质感。
4. 确认一张正式 Scene Master，并锁定其版本供裂变引用。

**输出 / 返工**

**输出：**正式场景母图（建议保留未覆盖版本）。

**不通过：**全局色调或空间关系错 → 重修 04/05；不可把它扩散为一组问题图。

**Gate B：**没有合格母图，不进入批量裂变。

### 06｜姿势、景别和机位裂变

**阶段标签：**系列生成

根据变化幅度选择文字，或白模＋文字，避免不必要的强重构。

**输入 INPUT**

- 正式场景母图
- 每张明确的 pose / 景别 / 机位目标
- 必要白模或构图参考
- 商品细节图

**操作 ACTION**

1. 场景变化小：母图＋文字控制目标动作。
2. 构图变化大：白模＋文字控制骨架、重心、机位、视差。
3. 身体朝向与相机方位分开写；允许新姿势带来真实褶皱和接触阴影。
4. 按需要安排全身、中景、侧/背侧、坐姿，避免重复朝向与重复动作。

**输出 / 返工**

**输出：**有差异且仍具系列一致性的裂变初稿。

**不通过：**动作错 → 调整姿势目标；视差错 → 重定相机/白模；脸与商品漂移 → 转相应修复模块。

**阶段结论：**裂变的是拍摄关系，不是人物身份与真实商品。

### 07｜逐张商业精修 → Gate C

**阶段标签：**成片验收

每张成片单独收敛，重新对齐母图视觉基准。

**输入 INPUT**

- 每张裂变初稿
- 正式母图及原商品细节
- 面部身份/九宫格参考（必要时）

**操作 ACTION**

1. 修正局部杂色、偏色、人物肤色与背景色差。
2. 面部不一致时判断需要重换脸还是只做后期校色。
3. 逐张校正印花、走线、领口、裤脚、穿插、坏手等。
4. 必要时 1K 角色换头 → 2K 提升 → 色彩匹配；复核身份与工艺未漂移。

**输出 / 返工**

**输出：**每张已确认的完稿候选图。

**不通过：**局部错误 → 留在 07 修；系统性母图问题 → 回查 05，避免逐张重复救火。

**Gate C：**外观一致、商品真实、场景协调、画面干净。

### 08｜输出、渠道适配与归档

**阶段标签：**交付

成片完成不等于交付完成，需保持版本和渠道可追溯。

**输入 INPUT**

- Gate C 合格图
- 本单渠道要求、尺寸比例、命名规则
- 源素材、种子图、母图和工程文件

**操作 ACTION**

1. 按实际平台规范输出分辨率、比例、格式和大小。
2. 核对 SKU / 色号 / 货号与成片是否正确对应。
3. 保留源素材、母图、裂变初稿、精修完稿和导出文件。
4. 必要时记录使用模型、主要修复方法及返工原因。

**输出 / 返工**

**输出：**完整可交付图像包及可追溯母图。

**不通过：**尺寸/命名/渠道要求错误 → 重导出；内容错误 → 返回 07 修图。

**交付结论：**正确的图片，以正确的文件进入正确的渠道。

## 4. 三道验收关口 · 可勾选清单

静态 Markdown 清单：由执行者人工勾选；与 HTML 交互版的本地勾选状态不互通。
<a id="gate"></a>

### 种子图：商品与人物是否正确？（GATE A / SEED）
- [ ] 商品品类、版型和上下装数量正确
- [ ] 服装主色、拼色与图案一致
- [ ] 领口、袖口、腰口、裤脚及重点工艺正确
- [ ] 人物身份、发型、年龄感及身材比例合理
- [ ] 完整全身可检查，手脚/鞋底没有明显错误
- [ ] 已保存经过修复的合格种子图

### 场景母图：能否支撑整组裂变？（GATE B / MASTER）
- [ ] 人物与商品继承 Gate A 或可信旧图
- [ ] 尺度、透视、机位、地面接触自然
- [ ] 人物受光、背景光场和色温协调
- [ ] 肤色、商品颜色和主体边缘无明显异常
- [ ] 背景明显脏斑、杂物和生成瑕疵已清理
- [ ] 已保存唯一明确的正式母图版本

### 裂变图：每张是否达到完稿标准？（GATE C / DERIVED）
- [ ] 目标姿势、景别、机位和构图符合计划
- [ ] 人物辨识度、发型和头颈比例正确
- [ ] 印花、拼缝、工艺和真实商品颜色正确
- [ ] 新姿势的褶皱、遮挡和接地阴影合理
- [ ] 整体色彩与场景母图视觉基准一致
- [ ] 局部杂色、坏手、背景异常已修复

### 导出文件是否具备交付条件？（DELIVERY）
- [ ] 渠道尺寸、格式和文件体积符合实际要求
- [ ] 货号 / 色号 / SKU 对应无误
- [ ] 母图与精修原文件已存档
- [ ] 导出图无误，文件命名与目标渠道一致

> **旧品快速路径提示：**跳过生成种子图 ≠ 跳过商品审核。可以用“可信旧图复核”替代 Gate A 的新图生成步骤，但商品、身份及关键工艺仍须确认。

## 5. 裂变方式判断器

核心问题：这次只是变动作，还是要重新建立摄影机与空间关系？
<a id="branch"></a>

### 当前这张裂变图要改变什么？
- 只改变人物姿势、视线或轻微构图；场景和机位基本不动
- 改变全身/中景、人物占比、拍摄角度，背景仍相对可控
- 大幅变化姿势和空间构图，需要确认重心、遮挡、机位与背景视差

### 母图＋文字（A / SMALL CHANGE）

适合站立换重心、微转头、抬手、自然坐靠等不明显改变场景空间关系的操作。

**关注：**减少无谓重构

### 母图＋明确机位/景别（B / MEDIUM CHANGE）

适合平视换侧角、全身改中景、轻微镜头高度变化；明确相机位置和人物身体朝向。

**关注：**检查人物占比

### 母图＋白模＋文字（C / LARGE CHANGE）

适合明显空间重拍、复杂坐姿、遮挡较多的机位迁移；白模负责骨架与构图，不继承身份、衣服和材质。

**关注：**核对背景视差

> **三轴必须分开描述：**Pose（人物身体姿势、头部视线与重心）／Composition（景别、主体位置、留白）／Camera（相机方位、高度与俯仰）。“人物转身”和“相机移动”不是同一种变化。

## 6. 异常修复与商业精修工具箱

按“出了什么问题”调用修复流程，并在对应场景下参考常用 Prompt；不要给每张图重复叠加全部处理。
<a id="repair"></a>

> **常用提示词参考：** 以下内容作为你个人工作流中的常用起始 Prompt，适合在修复工具箱场景下调用。它们是“起点模板”，实际使用时仍要按当前图像、模型和目标结果做删减、换词或补充，不建议不加判断地整段套用。

### R01 面部不一致 / 换脸 / 换头

**首先判断：是五官结构错，还是五官正确但颜色、明暗、质感不对？**

#### 结构不对 → 生成式修复

1. 马赛克或遮蔽问题面部区域，保留可用的身体、姿势、场景。
2. 提供面部九宫格作为多角度身份参考，重新生成局部面部。
3. 或者借助已有 Skill 的换脸/五官替换能力明确图源、发型、光影和头颈比例。
4. 如果需要整头替换，单独核查头发、脖颈、衣领衔接。

#### 结构正确 → 优先后期修复

1. 曲线 / Camera Raw 蒙版统一脸与身体的明暗、肤色。
2. 用参考母图做局部色彩匹配。
3. 借助中性灰、分频及局部 AI 修复清理斑驳杂色。
4. 避免为轻微偏色反复换脸导致辨识度下降。

> **个人实战备选链：**Nano Banana 3.1 Flash 的 1K 模式尝试换头 → 审核身份一致性与偏色 → 通过 2K 编辑/提升分辨率 → 色彩匹配 → 再审核五官、发型及服装。这里是使用者的经验路径，不代表所有版本或场景的保证性能。

**回退建议：**只出现在裂变图中的脸错，尽量修当前图；一整组都偏离同一个身份，则先检查母图和人脸参考源。

#### 常用提示词参考

##### 面部高清修复提示词（商业修片 / 马赛克面部修复）

适合先对问题面部做马赛克或遮挡，再引导模型参考人脸结构进行局部重建。

```text
商业修片：模特面部高清修复，修复图1模特面部细节，参考图2面部结构和五官细节。保持图1中的模特光影调性、色彩直方图不变、高光中间调暗调不变。真实发丝细节。4k，高清，raw。高级克制。
```

**使用提示：**可与九宫格人脸参考、局部遮罩修复结合使用。

##### 肤色均匀与五官细节优化（GPT Image 2.5）

适合在五官结构基本正确时，继续统一肤色与面部质感。

```text
保持原图环境背景修正均匀肤色，添加五官细节。不要有多余杂色，不要有过度锐化边缘，柔和清晰。不要更改五官结构。不要出现油腻质感，塑料质感，蜡质感。不要泛白，保持原图的饱和度和亮度。哑光雾面妆感。
```

**使用提示：**更适合“脸已对、质感不对”的情况；若五官结构错，应优先回到局部重生成。

### R02 偏色、肤色、色温与画质统一

| 问题 | 优先动作 | 注意点 |
| --- | --- | --- |
| 整张画面偏暖/偏冷/偏色 | 以正式母图、目标色为基准，曲线/Camera Raw/色彩匹配 | 保护商品真实颜色，不能只按氛围统一 |
| 面部与身体色温不一致 | 分区曲线、蒙版及局部色彩匹配 | 保留面部明暗和真实皮肤细节 |
| 人物与场景不融 | 检查受光、环境色、接地阴影，再做局部调色 | 不是简单给人物叠一层整体滤镜 |
| AI 杂色、脏斑、蜡感 | 局部生成修复、分频、中性灰、必要程度降噪 | 不能磨掉织纹、印花、毛孔 |
| 提升分辨率后颜色漂移 | 2K 结果与原母图色彩匹配，复查人物/商品 | 锐化增加不等于细节真实还原 |

> **个人经验，暂不写成通用预设：**你提到通过约 2%–4% 的洋红图层、使用“减去”混合模式尝试修正某些偏红图。是否有效取决于实际偏色、图层数值、色彩空间及不透明度；先在副本上 A/B 检查皮肤、灰阶和商品颜色，不作为所有图像的默认自动步骤。

#### 常用提示词参考

##### 降噪与数字伪影清理（修色降噪 / 通用参考）

适合画面存在数字噪声、压缩脏点、色彩噪点和 AI 脏纹理时使用。

```text
extreme denoise, remove visible noise, remove color noise, remove digital artifacts, remove grain, remove compression artifacts, suppress noisy micro-texture, clean noisy surfaces
```

**使用提示：**建议与“保护商品纹理、不要抹掉织纹/毛孔/印花”一并使用，避免过度清理。

### R03 局部印花、缝线、领口、裤脚与材质

**处理原则：**商品细节的局部纠错优先于整件重生。先明确到底是图案错、位置错、结构错，还是光影把正确工艺表现歪了。

1. 同时提供当前目标图、原始商品图、必要的局部工艺图或标注区域。
2. 仅修改明确区域；未标注的版型、纹理、颜色、动作和光场应尽量保留。
3. 印花修正核查内容、方向、比例、位置和被衣服转折遮挡的方式。
4. 缝线核查针脚数量、轨迹、间距、布面转折和遮挡逻辑。
5. 裂变姿势改变后，允许图案/缝线产生真实透视变形，禁止脱离布面漂浮。

> **当前个人模型经验：**GPT Image 2.5 可优先用于印花细节、局部还原与商品工艺修正；仍需以原始商品图验收，不因模型名自动判定正确。

**回退建议：**若整个款式被重设计，回到商品正确的种子图/母图；若仅局部失真，留在精修阶段修复。

#### 常用提示词参考

##### 缝线工艺修复（完整描述）（Nano Banana 3.1 Flash）

用于明确指定某个部位的缝线工艺，并要求参照工艺参考图进行替换。

```text
修改图1的袖口缝线工艺，参考图2的缝线工艺，将图1的改成双针缝线。
```

**使用提示：**适合结构明确、修改范围清晰的工艺修复。

##### 缝线工艺修复（标注区域）（Nano Banana 3.1 Flash）

适合已经在图上做红色标注，只需要模型聚焦局部区域时使用。

```text
修改图1红色标注的区域缝线工艺，参考图2的缝线工艺。
```

**使用提示：**若位置、轨迹、针脚数量很重要，建议同时提供放大局部参考。

##### 印花比例与图形修复（GPT Image 2.5）

用于修复印花大小比例、图形内容与贴附方式。

```text
修复修改图1中的印花大小比例和图形，参考图2中的印花大小比例和图形。是印上去的没有凹凸。
```

**使用提示：**适合印花被改错、放大缩小失真、图案内容偏移等问题。

### R04 人物与场景融合失败 / 背景污染

1. 查看是否把旧图家具、绿植、球、墙饰、旧阴影带到了新场景。
2. 必要时准备白底抠图或真透明主体，明确只继承人物、商品、姿势。
3. 补目标场景作为独立来源，检查人物尺度、地平线、机位高度与透视。
4. 观察背景实际主光方向、光质与阴影；无法判断时不要编造“窗边左上光”。
5. 重建人物脸、衣服和鞋子的受光、接地影与环境色。

**当前个人模型经验：**Nano Banana 系列可优先用于人物与环境融合；不把“优先尝试”写成对所有版本和输入方式的客观排名。

### R05 白模污染、姿势失真或新机位视差错误

1. 白模只提供身体骨架、重心、构图与必要摄影机关系，不继承脸、服装、材质或背景。
2. 明确当前任务是人物转身还是相机移动；相机移动时按新视角重建背景遮挡和视差。
3. 检查手臂、手掌、腿部支撑、脚底、服装接触褶皱与头颈比例。
4. 如果复杂变化多次失败，退回母图重新分解为单一目标动作与机位。

#### 常用提示词参考

##### 调整镜头视角与背景视差（机位调整 / 英文短句）

适合在母图基础上尝试相机绕主体移动，并要求背景环境同步发生透视变化。

```text
change the camera location, Orbit to the left 70°. 背景环境相对镜头随之改变角度，产生明显视差。
```

**使用提示：**使用时要区分“人物转身”与“相机移动”；若机位变化大，最好配合白模和文字控制。

### R06 高清、去噪、超分后的新问题

原始清理思路是去数字噪声、脏斑与 AI 伪影，而不是抹掉真实棉织纹、毛绒、毛孔、印花和针脚。可先轻度清理，只有明显缺陷和明确要求时加强。

> 如果出现蜡感、磨皮、边缘过锐、印花被重绘或肤色改变，降低修复强度，并对比修前和修后的面部、商品微细节。不以“2K/高清”替代实际质量检查。

## 7. 模型与工具按任务分工

这里记录的是当前个人实战优先级，不是模型榜单，也不是对外部模型能力的严格对照测试结果。
<a id="models"></a>

### GPT Image 2.5（局部商品修正）

**优先试用：**印花修复、局部工艺、视觉细节还原。

验收仍看真实产品细节；错误涉及整个版型时不要只靠局部补丁。

### Nano Banana 系列（场景融合）

**优先试用：**人物/主体进入目标环境、人物与背景融合、场景母图建立。

配合干净主体、独立场景图、商品细节参考。

### Nano Banana 3.1 Flash · 1K（角色换头）

**你的实践路径：**换头 → 身份审核 → 提升至 2K → 色彩匹配及精修。

产品命名、配置与可用性随平台更新，使用时以实际接口为准。

### 现有 Ecom Image Prompt Director（精准提示词）

用于厘清图源分工、换脸/换装、场景融合、局部工艺、姿势和机位的保留/修改边界。

它是辅助表达需求的工具，不承担自动图像验收。

### Photoshop / Camera Raw（色彩与画质）

曲线、蒙版、分区调整、局部清理、分频、中性灰、商品与肤色匹配。

适合已正确但仍需商业精修的图，不应盲目重新生成全部主体。

### 参考色彩匹配 / 局部 AI 校色（色彩算法）

对齐母图影调、修正人物与场景色温关系；必要时采用独立算法或图像模型。

参考区域和目标区域不同，校色也应区别处理。

> **模型路由不是唯一答案：**同一任务可预设首选与备选，但输出必须以商品细节、人物身份、场景光影和整体画质检查为准。建议后续记录模型版本、输入素材、分辨率、成功/失败原因，再决定是否固化为团队标准。

## 8. 最终审核维度与返工路径

遇到问题先定位最早出错的资产，避免“越修越散”。
<a id="qa"></a>

| 异常 | 先检查什么 | 优先返回节点 |
| --- | --- | --- |
| 所有裂变图服装印花相同位置都错 | 种子图、场景母图、商品细节参考 | 03 / 05：修商品基准 |
| 某一张裂变图手脚或 pose 错 | 该张目标动作与白模、生成结果 | 06 / 07：单张重做或局部修 |
| 所有图的人物脸都偏离身份 | 种子图、面部参考、母图 | 02 / 03 / 05：统一身份基准 |
| 只有一张脸色和身体不一致 | 该张面部编辑和局部肤色 | 07 / R01 / R02：局部修复 |
| 人物像贴在背景上 | 尺度、透视、主光、环境色、接地影 | 04 / 05：场景融合 |
| 机位换了背景却没变 | Camera 与 Pose 是否混淆、白模/视差 | 06 / R05：重建空间 |
| 超分后发型或印花改变 | 1K 与 2K 对比、原商品与人物参考 | 07 / R01 / R06：调整提升方式 |
| 图没问题但平台拒绝文件 | 尺寸、体积、格式、命名与平台规范 | 08：重新导出与校验 |

> **质量审核的优先顺序：**商品是否真实 → 人物是否一致 → 动作与摄影关系是否合理 → 场景与光影是否融合 → 画面是否干净 → 文件是否符合交付规范。

## 9. 文件版本与归档建议

下方是建议组织方式，不替代你现有的渠道文件命名规则。
<a id="files"></a>

### 按商品与颜色维护单独生产链

```text
货号_颜色/
├─ 00_Source/       原始静物、人物、背景、细节参考
├─ 01_Seed/         种子初稿、精修合格种子图（新款）
├─ 02_Master/       场景初稿、正式场景母图
├─ 03_Derived/      裂变图初稿、白模与必要控制参考
├─ 04_Retouch/      PSD / 精修过程 / 确认完稿
├─ 05_Export/       各渠道最终导出图
└─ 99_Notes/        简短任务记录、版本与返工信息
```

旧品快速路径可以不生成新种子图，但应在 `00_Source` 或 `02_Master` 中明确写明复用的旧图版本及其对应商品信息。母图版本不要被每次局部修复覆盖；需要更新母图时，记录更新原因与新版本。

### 最简版本记录建议

| 信息 | 记录内容 |
| --- | --- |
| 商品 | 货号 / 色号 / SKU / 季节（有则记） |
| 生产路径 | 新款标准 / 旧品快线 |
| 当前母图 | 文件名、版本、确认日期 |
| 目标成片 | 张数、全身/中景分配、目标用途 |
| 模型/工具 | 任务、模型版本、分辨率、特殊操作 |
| 问题与返工 | 原因、修复方式、是否影响母图 |
| 交付 | 渠道、文件位置、验收状态 |

> 平台输出规范因渠道及业务调整可能变化。本手册不假定统一的文件体积、尺寸或命名数字；最终以当前业务渠道规范和真实验收结果为准。
