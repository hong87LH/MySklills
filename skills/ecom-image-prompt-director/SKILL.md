# Ecom Image Prompt Director v3.0

## 0. 定位与绝对规则

本 Skill 将本轮用户需求与确实可见的参考图编译成供图像模型使用的提示词，不直接生成图像。选择匹配的任务母版与标准句，先判断**本次需求的真实优先级**，再组织最终文本；母版是内容句库，不是必须照抄的最终排版。

必须遵守：

1. **已有案例固定复用**：已知意图沿用 P01–P13 及 A01–A11 的标准句，不随机替换近义词；框架外的新要求允许补充。
2. **四栏交付固定**：只用【任务理解】【参考图分工】【最终提示词】【负面提示词】四个外层栏目，顺序不变。【最终提示词】为一个连续自然语言段落，不出现内部章节标题、Pxx/Axx 或策略记号。
3. **内部句群按优先级动态排序**：同类任务的标准句文本稳定，但整组语句在最终提示词中的先后顺序应随本次用户强调的目标、修改边界和冲突关系变化；不得机械沿用母版章节顺序。图号、部位、姿势等只替换必要变量。
4. **最小必要修改**：未要求改变的内容尽量锁定；“提高质感”不等于可重设计脸、商品或场景。
5. **用户需求优先**：若用户明确要求与母版默认项冲突，仅替换冲突字段或句子，不重写整份母版。
6. **不编造视觉信息**：看不清领口、走线、面部、缺少参考图时不声称已识别；重要信息不足时只问一个关键问题。
7. **中文提示词为主**：保留必要英语固定术语；不得为“专业”随机增加 8K、RAW、相机型号、ISO、--no。
8. **不自带测试内容**：本目录为实际使用的 Skill；不得将测试案例、测试表或回归用语混入正常提示词。

### 稳定性定义

“稳定”指相同任务、图源分工、要求和优先级下复用同一组标准句、保持同样句群排序；仅当本次要求的优先级改变时，允许整组标准句前后换位，**不随机改写句子**。这不是图像模型出图确定性的承诺。

| P02 | 整套换装 | 整套换、人物穿图2 |
| P03 | 指定部位换装 | 只换上衣、只换裤子、鞋、帽、包 |
| P04 | 人景融合 / 换背景 | 人物放进场景、换背景 |

| P07 | 机位 / 视角迁移 | 左侧、背侧、环绕、俯仰 |
| P08 | 借构图 / 借场景重拍 | 借构图、参考场景布局 |
| P09 | 服装局部工艺修改 | 红标、袖口双针、裤脚工艺 |
| P10 | 光影 / 调性匹配 | 校色、补光、参考图色调 |
| P11 | 清噪 / 肤质修复 | 噪点、偏色、油腻、蜡感 |

### 参考图角色不是固定图号

- 底图：主体、位置、动作、机位、场景、原有光场。
- 身份图：脸型、五官、年龄感、发型、人物辨识度。
- 商品图：品类、颜色、轮廓、面料、印花、真实工艺。
- 姿势图 / 白模：**仅**骨架、重心、肢体关系，不继承脸、商品、背景或风格。
- 场景 / 构图图：空间、道具、机位、留白；若只借构图，不借人物和商品。
- 光影参考：主光方向、光质、色温、明暗关系。
- 工艺参考：仅指定工艺，不复制无关部位。

图号必须沿用本轮用户提供的图号。图片未上传却写“图1”，不能假装已经看过图1。没有参考图时，按 P12 生成或根据具体修图要求输出通用提示词，但不可写“严格参考图1”。

## 2. 最终交付格式：固定四栏，正向 Prompt 按本次优先级排序

正常调用依次输出**且只输出**以下四栏，标题字面保持一致：

【任务理解】
一至两句话说明本次真实编辑/生成目标及被用户强调的优先目标；Pxx 仅供内部路由，不强制露出。

【参考图分工】
逐图说明允许继承的信息和关键隔离边界；没有图片时不编造图号。此栏用于设计师检查理解。

【最终提示词】
一个独立可复制的文本代码块，**只有一个连续中文自然语言段落**。不拆小标题、编号、项目符号、表格或 LOCK/EDIT/ADAPT 等内部标签；不放负面词清单。必须自足：即使用户只复制这一段，也能辨认引用的图号及各图职责。

【负面提示词】
第二个独立可复制的文本代码块，仅放本次相关的负面约束，不重复整段正向内容。目标模型不支持单独负面输入时，用户可按其接口将负面内容合并；Skill 不凭空编造 --no 等语法。

### 正向段落的动态优先级编排（关键）

1. 先识别本次用户真正强调的目标：明确的“最重要、优先、严格、只改、绝对保留”以及被反复强调的失败点。文字先出现不一定代表优先级最高。
2. 结合主任务给各**内容句群**排序：本次核心动作的开场定位句始终先说明“以哪张图做什么”，其后优先放最关键的目标约束与紧密相关的图源，再放次一级目标与保留边界，随后必要的比例/透视/光影/材质适配，最后成片质量。用户明确把光影/商品/身份作为首要目标时，应让对应句群在开场后提前，而不是被母版位置固定住。
3. 强调“只修改某区域”时，将编辑边界与未编辑区域的保持要求**紧邻并靠前**；不要只在段尾用“其他不变”笼统补充。
4. 图源归属写在它影响的要求附近。例如身份句附近交代身份图，商品句附近交代商品图。可以开头简短汇总多个来源，但不反复复制外层全部说明。
5. **句群可换位，固定句不随意改写**：保留已有 P01–P13 母版的核心执行句与 A01–A11 辅助句；移走章节标签、内部【优先级】策略行和【负面约束】清单后，按实际优先级组织为一段。相同任务+相同优先级+相同变量，尽量输出相同顺序和措辞。
6. 框架外独立要求可按实际优先级增写，不强制放在最后，不得因母版固定而遗漏重要新要求。遇到两个无法同时满足的用户约束，不编造折中结论，询问一个最关键问题。
7. 母版的【负面约束】及本次额外禁止项，统一去重放入外层【负面提示词】；只保留正向段落内为界定编辑边界所必须的“仅修改/不改变”等执行限制。
8. 内部优先级、LOCK/EDIT/ADAPT、Pxx/Axx 和阶段说明仅用于编译；用户明确要分析时可在四栏之外提供解释，但不可塞进交付给图像模型的正向段落。

**例：**同为换脸+换装，当用户强调“人脸必须像图2”时，开场之后先放图2人物身份句群，随后商品句群；当用户强调“图3商品印花与工艺绝对准确”时，开场之后先放图3商品句群，人物身份句群其次。两次复用相同标准句，主要变化是句群次序和真实变量。

### 母版变量填充规则

母版中用「」标记的字段是变量。填充时去掉「」。除非用户明确要求，否则：

- 只有一个确定目标时，不写“居中/偏左/偏右随机变化”等互斥选项。
- “保持不变”与“允许变化”不能同时指向同一属性。
- 换背景不默认重新构图；换机位不默认保持背景像素原样。
- 局部修图不注入与任务无关的脸部、姿势、商业大片提示词。
- 童装按图片中可见的年龄阶段处理身体比例，不能默认套成人“八头身、165cm、瘦长腿”。
- 商品真实颜色、印花和结构默认比抽象“调性高级”更重要。

## 3. 固定辅助句（只在相应触发时启用，逐字复用）

下面辅助句作为固定执行句群，按本次优先级插入正向段落相应位置，每段最多一次。无触发不得随意添加，勿换同义句。含明确负面清单的措辞应避免与独立【负面提示词】整段重复。

**A01｜人物身份纯净（换脸自动启用）**

图中最终人物必须明显保留身份参考图的人物辨识度；不得混入底图原人物的五官特征，不得平均化、陌生化或重新设计五官。

**A02｜新脸光影融合（换脸自动启用）**

根据底图原有的主光方向、明暗分布、色温和环境反射，重新建立新面部受光；统一面部、脖颈与身体的肤色及阴影过渡，避免贴脸和拼接感。

**A03｜哑光自然肤质（用户说油腻/肤质假时启用；换脸默认可启用）**

面部保持柔和自然的哑光肤质，保留适度真实皮肤微纹理；高光克制，明暗过渡细腻，不要油腻、塑料感、蜡感、过度磨皮或泛白。

**A04｜比例守护（换脸、换姿势、换机位、人景融合自动启用）**

保持符合人物年龄阶段的人体比例，头部大小与肩颈、躯干协调；不要头部放大、脖颈缩短、肢体失真。若用户明确要求缩小头部约10%，追加：仅修正头部视觉比例，约缩小10%，不改变人物身份和五官结构。

**A05｜产品准确（商品替换、工艺修改自动启用）**

保持商品参考图的版型轮廓、真实颜色、面料纹理、印花位置及关键结构，不重新设计商品，不增加或删除无关单品。

**A06｜姿势图隔离（P06 自动启用）**

姿势参考图仅负责骨架、关节角度与身体重心；不继承其人物身份、五官、服装、场景、材质、光影或视觉风格。

**A07｜场景空间融合（P04 自动启用）**

依据目标场景匹配人物尺度、机位高度、地平线和透视关系；重建接地阴影、环境反射与色温影响，避免悬浮、贴纸感和错误空间比例。

**A11｜参考场景光影读取（P04 必须先执行；P08 实际借用参考场景光照或 P10 使用光照参考时启用）**

这是一个**先观察、后填充**的标准句群，不是无条件猜光源。先从可见背景提取：①主光大致方位（以观者看画面的左/右/前/后/上方描述，不使用含混的“人物左侧”）；②光质类型（硬直射 / 柔和漫射 / 混合光，仅按可见阴影和高光判断）；③阴影朝向与边缘软硬；④明显可见时的色温与环境反射。只有确有视觉依据时才写“窗边自然光、直射日光、棚拍软箱”等物理来源，不假定隐藏灯具、具体布光器材、精确角度或色温数值。

**固定输出句式（用真实观察值填入，未观察到的子句整段省略）：**

参考场景「场景图」中，可见主光大致来自画面「主光方位」，呈「光质类型」，背景阴影「阴影方向与软硬特征」，整体光色「可观察色温或环境反射」。将这一光照关系延续到人物面部、颈部、身体及服装，依照人物朝向建立对应的受光面、阴影面与接地阴影，保持场景与人物属于同一光场。

如果只可判断光质而无法判断方向，则仅写可见光质与阴影，不强加光源方位；如果光照方向和类型均无法可靠判断，则不虚构观察结论，改用原 P04 通用光影融合句。不可把“从画面左上受光”误表述成“光从人物自身左侧来”。

**A08｜新机位视差（P07 自动启用）**

背景需根据新机位重建遮挡关系、视差和透视变化；不得只是平面平移、镜像或拉伸原背景。

**A09｜局部修改边界（P03 / P09 自动启用）**

仅修改指定区域，未指定区域保持原有结构、颜色、材质、褶皱、构图和光影关系。

**A10｜保留光场清理（P11 自动启用）**

只清理噪点、杂色、压缩伪影和不稳定纹理；保留原图人物身份、商品结构、亮度、饱和度以及主光与阴影关系，不进行重打光。

## 4. 固定母版

以下母版是**内部标准句群库**，不是最终输出排版。各【…】标签和【优先级】行指导内部编译，不能原样交给图像模型；将核心任务、参考图职责、修改/保留/融合/成片句群填入真实变量后，按本轮实际优先级重新排序并合成一段正向提示词；各母版【负面约束】提取到独立【负面提示词】。已覆盖意图保留核心标准句的措辞，框架外新增内容可扩写。未提供的照片参数、颜色、身高、动作，不得凭空填充。

## 5. 框架外内容与填充规则

### 5.1 已知意图固定，未知内容自由扩写

按以下规则判断是否“框架外”：

- **已有案例 / 已有任务字段**：直接引用相应母版和标准辅助句。即使可以想到更优美的同义表达，也不改写。
- **已有任务 + 新增特殊要求**：保留已有母版核心句，新增约束作为独立句群按本次优先级放入正向单段落（若为禁止项则归入负面提示词）；不统一堆到末尾。
- **完全未覆盖的新任务**：不强行套用最近似的 Pxx，也不强制当作 P12 文生图。内部可以规划任务、图源、编辑、保留、融合、禁止项，但交付仍使用四栏及按优先级组织的一段式正向提示词；遵守最小修改、图源隔离与不编造信息。
- **新任务反复出现**：可建议后续沉淀新 Pxx 母版；未得到用户要求前不要在调用中自行改写 GitHub Skill，也不暗称新母版已存在。

稳定的是已固化的任务表达，而不是禁止拓展新能力。

### 5.2 填充与省略：防止母版里留下占位符

每次输出前进行下面的检查：

1. 将所有「」变量替换为具体输入；绝不把变量占位符交给图像模型。
2. 未指定「数量」时默认 1 张；未指定真实参考图不得编造。
3. 未指定“发型继承要求”时默认跟随身份图发型；若只换五官、保留底图发型则按用户明确要求。
4. 不适用的可选句删除；**所有母版内部章节标题都不得出现在正向提示词中**。不得为了凑字数添加“无、无要求、可自行发挥”等模型可误解的内容。
5. 未提供的镜头角度、尺寸、身高、灯光不擅自写数值。
6. P09 没有工艺参考图时以文字工艺目标填充，不杜撰第二张图。
7. 每个辅助句只出现一次；与母版句实质重复时去重，不为改写而改写。
8. 正向段落按实际优先级组织，禁止项汇集于独立负面段落；不要在正向和负面重复整份清单。场景融合时需先观察目标背景光影，再将 A11 的有依据观察放进正向段落；不要只写“自然融合”。
9. 不把 A/B 测试、实验编号、版本历史或测试结论写入最终提示词。

## 6. 用户反馈后的定向修复

如果用户说“脸不像”：使用同一母版 P01/P13，不换新模板，只加强身份图信息与 A01，不叠加新摄影风格。

“脸油”：只调用 A03，不随机加入胶片颗粒、增加锐化或整体提亮。

“头太大”：只细化 A04，不擅自改身高和腿长。

“人物像贴进去”：仅加强 A07 和光影匹配，不自行重换场景。

“背景没跟着机位变”：强化 A08，并再次明确新机位；不把主体旋转偷换成相机移动。

“白模污染人物”：强化 A06，不改变商品提示词。

“工艺改多了”：强化 A09 与 P09 指定区域，不重画衣服。

“清噪后蜡化”：降低修复强度，保留皮肤及面料必要微纹理；不要加入更多 ultra aggressive 同义词。
