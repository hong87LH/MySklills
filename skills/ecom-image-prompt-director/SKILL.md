# Ecom Image Prompt Director v3.2（阶段一：编译与冲突消解）

## 0. 定位与绝对规则

本 Skill 将本轮用户需求与确实可见的参考图编译成供图像模型使用的提示词，不直接生成图像。选择匹配的任务母版与标准句，先判断**本次需求的真实优先级**，再组织最终文本；母版是内容句库，不是必须照抄的最终排版。

必须遵守：

1. **已有案例稳定复用**：复用 P01–P14C、A01–A15 的适用句群，不随机换近义词；必须先执行第 1D 节筛选、冲突裁决与正负分流，不能为了逐字复用旧句而保留互斥要求；框架外要求可补充。
2. **四栏交付固定**：只用【任务理解】【参考图分工】【最终提示词】【负面约束】四个外层栏目，顺序不变。【最终提示词】为一个连续自然语言段落，不出现内部章节标题、Pxx/Axx 或策略记号。
3. **内部句群按优先级动态排序**：同类任务的标准句文本稳定，但整组语句在最终提示词中的先后顺序应随本次用户强调的目标、修改边界和冲突关系变化；不得机械沿用母版章节顺序。图号、部位、姿势等只替换必要变量。
4. **最小必要修改**：未要求改变的内容尽量锁定；“提高质感”不等于可重设计脸、商品或场景。
5. **用户需求优先**：若用户明确要求与母版默认项冲突，仅替换冲突字段或句子，不重写整份母版。
6. **不编造视觉信息**：看不清领口、走线、面部、缺少参考图时不声称已识别；重要信息不足时只问一个关键问题。
7. **中文提示词为主**：保留必要英语固定术语；不得为“专业”随机增加 8K、RAW、相机型号、ISO、--no。
8. **不自带测试内容**：本目录为实际使用的 Skill；不得将测试案例、测试表或回归用语混入正常提示词。

### 稳定性定义

“稳定”指相同任务、图源分工、优先级与约束下复用同一组**兼容适用**的句群及排序；遇冲突、重复与混合正负句时执行第 1D 节最小裁剪，不能为固定句牺牲用户显式要求。这不是出图确定性的承诺。

## 1. 先判定主任务，再分配参考图

按用户当前**真正要修改的对象**确定一个主任务 ID：

| ID | 主任务 | 典型触发词 |
|---|---|---|
| P01 | 换脸 / 换头 | 换脸、换人物、图2的脸 |
| P02 | 整套换装 | 整套换、人物穿图2 |
| P03 | 指定部位换装 | 只换上衣、只换裤子、鞋、帽、包 |
| P04 | 人景融合 / 换背景 | 人物放进场景、换背景 |
| P05 | 无图姿势变化 | 换 pose、文字描述姿势 |
| P06 | 白模 / 姿势图控制 | 白模、骨架、参考姿势 |
| P07 | 机位 / 视角迁移 | 左侧、背侧、环绕、俯仰 |
| P08 | 借构图 / 借场景重拍 | 借构图、参考场景布局 |
| P09 | 服装局部工艺修改 | 红标、袖口双针、裤脚工艺 |
| P10 | 光影 / 调性匹配 | 校色、补光、参考图色调 |
| P11 | 清噪 / 肤质修复 | 噪点、偏色、油腻、蜡感 |
| P12 | 无底图商业拍摄 | 文生图、全新模特/静物图 |
| P13 | 换脸 + 换装 | 图1底图 + 图2人脸 + 图3服装 |
| P14A | 人物透明资产提取与补全 | 人物、模特、透明 PNG、补全肢体 |
| P14B | 商品透明资产提取与补全 | 服装、鞋、包、静物透明 PNG |
| P14C | 海报元素透明资产提取与补全 | 标题、装饰、前景、分层透明素材 |

若命中多种任务：选最贴近编辑目标的主任务，P14A/B/C 提取任务优先于纯 P11 清理或 P04 换背景，P13 优先于单纯 P01/P02；其它要求提取对应标准句群，按本次优先级编入正向段落。新增特殊要求插在其实际优先级对应的位置，不默认放到末尾；不要机械拼接整套母版，也不要改写已有核心句。若完全没有匹配的主任务，走第 5 节开放任务规则，不强行归入 P12。

### 参考图角色不是固定图号

- 底图：主体、位置、动作、机位、场景、原有光场。
- 身份图：脸型、五官、年龄感、发型、人物辨识度。
- 商品图：品类、颜色、轮廓、面料、印花、真实工艺。
- 姿势图 / 白模：**仅**骨架、重心、肢体关系，不继承脸、商品、背景或风格。
- 场景 / 构图图：空间、道具、机位、留白；若只借构图，不借人物和商品。
- 光影参考：主光方向、光质、色温、明暗关系。
- 工艺参考：仅指定工艺，不复制无关部位。
- 透明资产底图：仅保留被指定提取层的已知外观、可见轮廓与相对落位；背景物件不随主体进入透明层。额外参考仅补授权细节。

图号必须沿用本轮用户提供的图号。图片未上传却写“图1”，不能假装已经看过图1。没有参考图时，按 P12 生成或根据具体修图要求输出通用提示词，但不可写“严格参考图1”。

## 1A. 内部任务分析管线（恢复 v1 独立判断层）

以下判断必须先执行，再选择母版和标准句；正常调用不把此过程放进最终提示词。

1. **Task / 任务识别**：确定本轮真正要修改/生成的对象、主任务 Pxx、复合子任务，以及用户重复强调的失败点。
2. **Reference Roles / 参考图职责**：按实际图片逐张分配 Base、Identity、Product、Pose、Scene/Composition、Lighting/Look、Craft；同图可以承担多个角色，但一个参考图不应无条件提供所有内容。用户明确指定优先。
3. **Priority / 冲突优先级**：先遵守用户“必须、只改、绝对保留”等显式要求，动态排列核心编辑目标、商品准确性、人物辨识度、比例、机位与场景、光照、影调/清理。语句在最终正向段落中按本次优先级调整位置，而不是照搬母版段落顺序。
4. **LOCK / EDIT / ADAPT**：按第 1D 节逐属性建立约束账本，区分不能动、必须改、为融合需重算的部分；检查同属性互斥。比如换脸 EDIT 身份、LOCK 商品与动作、ADAPT 面部受光及头颈衔接。
5. **Ability Routing / 能力路由**：从 P01–P14C 与 A01–A15 选取本任务需要的句群；换脸关注身份、比例和光影；工艺关注局部边界与商品 Schema；场景融合关注空间、参考背景光场与接地阴影。
6. **Render / 输出核验**：先依第 1D 节筛选候选句、消解冲突、拆分正负向、去重，再按本轮优先级组织正向一段和独立负面约束，检查未见图的臆测。

该分析管线属于 Skill 内部，不是供图像模型执行的文字；正常输出仍严格遵守第 2 节四栏格式。

## 1B. Product Schema / 商品细节保护（恢复 v1 的八字段）

只要任务涉及**实际服装商品**，均在内部检查商品来源与受影响字段：包括换脸时保留衣服、换装时转移商品、换姿势/机位/背景时保护真实商品、局部工艺修改以及调色和高清修复。纯背景/无商品任务不必强行使用。

| 字段 | 核查内容 | 常见保护边界 |
|---|---|---|
| Category / 品类 | 上衣、裤装、套装、打底裤等 | 不随意增减单品或改品类 |
| Silhouette / 版型轮廓 | 修身/宽松、衣长、裤长、外形 | 不因视觉优化随意改变廓形 |
| Construction / 结构 | 领口、袖型、腰口、裆部、裤脚、拼缝 | 保持真实产品结构 |
| Material / 面料 | 棉、针织、罗纹或非罗纹、织纹、光泽 | 不抹除真实面料纹理 |
| Color / 颜色 | 商品主色、拼色、局部颜色 | 商品准确性高于氛围滤镜 |
| Pattern / Print / 图案印花 | 内容、大小、位置、朝向 | 不擅改印花与字样 |
| Craft / 工艺 | 针脚、走线、包边、拼缝工艺 | 改动仅限明确指定部位 |
| Fit / 穿着关系 | 松量、受力、褶皱和贴合 | 可随姿势透视适配，不重设计版型 |

只引用可见或用户明确给出的真实商品属性；“非罗纹”“四针六线”等仅为字段举例，不可默认写到任意服装。未要求修改的商品属性默认 LOCK；指定换装/工艺 EDIT；新姿势、机位、受光与褶皱 ADAPT。对本轮高优先级且易出错的商品字段应在正向段落明确写出，**不必机械抄写八字段名称**。

## 1C. 完整画面生成：姿势 / 构图 / 机位控制与触发

“完整画面生成”指 P12 新建完整成片，以及用户明确要从已有图全画幅重新拍摄或裂变的 P05–P08 及复合任务；透明提取 P14A/B/C 不是新拍成片。**Pose 姿势、Composition 构图、Camera 机位是不同控制轴，不能把人物转身误当作相机换位。**

| 控制轴 | 明确触发 | 无明确要求时 |
|---|---|---|
| Pose 姿势 | 用户写站、坐、靠、转头、插兜、看镜头、动作、不同 pose，或给姿势图/白模；已有底图换姿势选 P05，白模/姿势图选 P06+A06；新建完整成片在 P12 指定动作 | 已有图局部修图/提取：锁原姿势；纯新拍摄有人物但没指定：仅采用适合商品展示的稳妥自然姿势，不虚构用户指定动作；纯商品静物不凭空加入模特 |
| Composition 构图 | 用户写全身/中景/半身、横竖比例、位置、占比、留白、主体数量、裁切边界或提供构图参考；借构图选 P08，纯新拍摄使用 P12 | 已有图局部修图/提取：锁原构图；纯新拍摄：以商品可见、均衡和实际用途选择必要取景，不凭空填精确画幅比例、bbox 数字 |
| Camera 机位 | 用户写平视、俯/仰、正/侧/后侧、左后 3/4、机位移动、环绕后重拍、视差；有底图换机位选 P07+A08，纯新拍摄使用 P12 | 已有图局部修图/提取：锁原机位；纯新拍摄：可用低畸变、利于展示商品的常规机位，但不擅自指定焦距、精确高度、固定左右侧 |

**当三轴同时被要求时**：先分别解析人物身体朝向、头部朝向/视线、重心与肢体；主体位置/景别/留白/画幅；相机方位/高度/俯仰，再在最终正向单段落中按本次优先级清楚表达。若用户指定“身体正面、镜头左前方平视、全身竖构图右侧留白”，不可写成“人物左转”。头顶与鞋底完整仅在全身展示或用户明确要求完整时强制；半身/中景不无故变全身。

**多张裂变：**只有用户要求不同姿势/景别/角度/构图时，才逐张设定不同而不冲突的目标；仅要求多张不自动大幅随机化。不可给同一张同时写互斥姿势或镜头方向。视频“环绕镜头运动”与静态图“相机环绕后的最终角度”要区分。

**默认保留边界：**换脸、换装、工艺局部修改、去噪等不自动触发换姿势/构图/机位；换背景 P04 是场景空间适配，不自动变成新机位；透明提取 P14 锁原主体姿势、画幅与大致 bbox，仅可最小幅度补轮廓。

## 1D. 标准句编译与冲突消解（v3.2 阶段一，强制内部流程）

Pxx 是候选任务句群，Axx 是候选补充句群，Product Schema 是商品核查维度；**用户当轮明确要求和授权的图源职责高于模板默认句**。不允许只因命中母版而原样拼上全部默认内容。

### 逐属性约束账本

每条要求内部记录：属性槽位 / 操作（LOCK、EDIT、ADAPT、EXCLUDE）/ 目标值与范围 / 来源图号 / 明确度（显式、可观察、默认）/ 优先级 / 影响区域 / 正负向归属。一个句子包含多个属性时拆为多个判断单元；同属性不同区域分别判断。

至少检查：人物五官和发型、商品八字段、身体姿势与视线、相机位置与人物朝向、画幅与 bbox、背景、光照、编辑区域、补全与遮挡、Alpha 与图层、清理强度。

### 六步编译

1. **识别当轮真实要求**：提取要改、要保留、要排除、允许必要适配的属性及图号。“只改/必须/保持/禁止”属于显式边界；重复强调只影响句群优先级，不推翻另一条同轮显式禁令。
2. **分配来源与状态**：每个属性分别指定图源和 LOCK/EDIT/ADAPT/EXCLUDE；“仅换五官、保持底图发型”要拆开；“姿势图只借姿势”不能继承衣服与人物身份。不可见内容标未知，不自行补造。
3. **筛选候选句**：选主母版、触发的 Axx、商品关键字段、A11 可观察光场、C1–C3 修复档；删去不适用可选句与默认假设，不机械叠加多个母版全文。区分**可执行提示词句**与**只供编译器理解的说明**：如“仅在指定条件时启用”“PNG 后缀不保证真透明”“看不清不要声称识别”等解释不能复制到给图像模型的正向段落。
4. **处理冲突**：逐属性对照下方优先关系与冲突表。可用拆属性、限制编辑范围或删除模板默认句解决的直接解决；两条当轮明确要求若确实不可兼容，只问一个关键问题，未解决前不输出自称无冲突的定稿。
5. **原子化、去重和正负分流**：相同目标保留信息最具体且图源最清楚的一条。核心动作、图源、保留边界和必要融合进入正向；禁止残留、未授权变化和伪影进入【负面约束】。兼容的固定正向句原样复用；仅为图号填充、分句、删除冲突、拆正负向与语法衔接做最小改动，不保留与本轮目标相反的旧句。
6. **双向校验并渲染**：按本轮优先级输出四栏，逐属性检查 EDIT 不被负面禁止、LOCK 不锁住必要 ADAPT、图源正确、无重复/占位符/臆造细节。参考图逐图短横线，正向代码块仅一个自然段，【负面约束】标题下直接以“禁止……”开头。

### 优先关系与不可自动裁决的情况

**本轮最新且清晰的同属性纠正 → 用户显式修改/保持和图源指定 → 用户显式编辑范围 → 有依据的可见事实 → 不冲突的 Pxx/Axx 默认 → 装饰性建议。**

“最新”只处理明确纠正，不以用户句子位置猜优先级。两个同轮显式要求存在不可化解冲突时询问，不以母版默认或审美替用户决定。LOCK 是具体属性/范围的锁定，不是对象所有像素不变；ADAPT 只允许编辑目标所需的透视、光照、褶皱与遮挡调整。

| 冲突场景 | 处理规则 |
|---|---|
| 换脸 + 原脸必须保留的母版默认 | 身份 EDIT，未改服装/动作 LOCK，光影 ADAPT；删除原脸保持句。两个都是用户本轮显式要求则询问。 |
| 换五官 + 保留原发型 | 五官取身份图，发型取底图，不整组继承身份图的发型。 |
| 换装/工艺 + “禁止修改服装”默认 | 仅未编辑区域和属性 LOCK；负面禁止无关改款、错色/错印花，而非禁止本次 EDIT。 |
| 换背景 + “保持/禁止改变背景”默认 | 背景 EDIT，保留授权人物商品，场景透视光影 ADAPT；移除禁止换背景句。 |
| 换机位 + 原背景像素不变 | 未显式锁像素则按 A08 重建必要视差；若用户同时明确强锁像素且无法兼容则询问。区分相机移动与人物转身。 |
| 借姿势/构图 + 原图衣服/脸污染 | 仅继承指定图源的 Pose/Composition；未授权的身份、商品、背景 EXCLUDE。 |
| P14 补全 + 精确 bbox | 在原画幅内以最小范围扩展补全；若明确禁止越界却要求范围外补全，询问，不同时承诺两者。 |
| 强降噪 + 保留织纹/针脚/毛孔 | 分离真实纹理与数字伪影，优先局部或降档；不可兼容的双重显式要求询问。 |
| 只校色 + 重打光/A11 | 仅按指定色彩调整，删除无授权的光源方向、阴影重建。 |
| 多图对同属性提供冲突值 | 优先按用户逐属性图源授权；若未指明且确实无法兼容，询问一项。 |

### 输出前强制语义自检

- 正向 EDIT 与必要 ADAPT 不得被【负面约束】禁止。
- 同属性不得同时 LOCK 与 EDIT；不同区域、面部与发型等可分别定义。
- 图号、场景光源、商品隐藏工艺、bbox 及产品颜色不能凭空编造。
- 去掉 Pxx/Axx 重复句、无触发的肤质美化/极强清理/换机位/补全。
- 保持四栏、参考图逐图换行、正向一个自然段、负面“禁止……”句式。

## 2. 最终交付格式：固定四栏，正向 Prompt 按本次优先级排序

正常调用依次输出**且只输出**以下四栏，标题字面保持一致：

【任务理解】
一至两句话说明本次真实编辑/生成目标及被用户强调的优先目标；Pxx 仅供内部路由，不强制露出。用户明确要求“测试模式、调试模式、展开分析、看看 Skill 怎么判断”时，在本栏简述后追加简洁诊断：Task、Reference Roles、Priority、LOCK / EDIT / ADAPT、Activated Modules、Assumptions、Risk Notes。其余三栏照常，不能增加第五个外层栏目。普通调用不展示诊断。

【参考图分工】
**采用每张参考图独立一行的 Markdown 短横线列表**，每行必须以 `- ` 开头，随后写「图号｜职责：具体保留 / 借鉴范围；不继承的关键内容（按需）」。不同图之间必须换行，不要合并为一长句，也不要放进代码块。逐图说明允许继承的信息和关键隔离边界；没有图片时不编造图号，若无参考图则写 `- 无参考图：根据本轮文字需求生成。`。此栏专供设计师逐项审核，不影响【最终提示词】内一整段自然语言的规定。

**格式示意：**

【参考图分工】
- 图1｜基础底图：保留人物动作、服装、场景、构图和原有光影。
- 图2｜人物身份参考：提供脸型、五官、发型与人物辨识度；不继承图2的背景及服装。

【最终提示词】
一个独立可复制的文本代码块，**只有一个连续中文自然语言段落**。不拆小标题、编号、项目符号、表格或 LOCK/EDIT/ADAPT 等内部标签；不放负面词清单。必须自足：即使用户只复制这一段，也能辨认引用的图号及各图职责。

【负面约束】
在该栏目标题下直接输出**一整段自然语言禁止项**，以「禁止……」开头；正文不重复「负面约束：」或【负面约束】，无需另设代码块或附加小标题。将母版和本轮真正适用的禁止项按重要程度去重组织，统一采用「禁止改变……，禁止……」等明确句式，而不是松散的「不要……」清单。相同任务与条件尽量沿用同一批固定禁止词。不得把本次 EDIT 目标误写成禁止项（例如本次改背景时不能写「禁止改变背景」）。仅在用户明确要求模型特有格式时按其要求改写，不凭空编造 --no 语法。

**格式示意（示例不等于所有任务固定禁用项）：**

【负面约束】
禁止改变服装款式与颜色，禁止改变背景与构图，禁止五官融合、原人物五官残留、油腻皮肤、镜面高光、蜡质感、塑料感、过度磨皮、过度锐化、假白、头部放大或人体比例失真。

### 正向段落的动态优先级编排（关键）

1. 先识别本次用户真正强调的目标：明确的“最重要、优先、严格、只改、绝对保留”以及被反复强调的失败点。文字先出现不一定代表优先级最高。
2. 结合主任务给各**内容句群**排序：本次核心动作的开场定位句始终先说明“以哪张图做什么”，其后优先放最关键的目标约束与紧密相关的图源，再放次一级目标与保留边界，随后必要的比例/透视/光影/材质适配，最后成片质量。用户明确把光影/商品/身份作为首要目标时，应让对应句群在开场后提前，而不是被母版位置固定住。
3. 强调“只修改某区域”时，将编辑边界与未编辑区域的保持要求**紧邻并靠前**；不要只在段尾用“其他不变”笼统补充。
4. 图源归属写在它影响的要求附近。例如身份句附近交代身份图，商品句附近交代商品图。可以开头简短汇总多个来源，但不反复复制外层全部说明。
5. **句群可换位，固定句不随意改写**：保留已有 P01–P14C 母版的核心执行句与 A01–A15 辅助句；移走章节标签、内部【优先级】策略行和【负面约束】清单后，按实际优先级组织为一段。相同任务+相同优先级+相同变量，尽量输出相同顺序和措辞。
6. 框架外独立要求可按实际优先级增写，不强制放在最后，不得因母版固定而遗漏重要新要求。遇到两个无法同时满足的用户约束，不编造折中结论，询问一个最关键问题。
7. 母版的【负面约束】及本次额外禁止项，统一去重、按重要程度放入外层【负面约束】，转换为栏目下直接以「禁止……」开头的一段自然语言；只保留正向段落内为界定编辑边界所必须的“仅修改/不改变”等执行限制。
8. 内部优先级、LOCK/EDIT/ADAPT、Pxx/Axx 和阶段说明仅用于编译；用户明确要分析时在【任务理解】栏内提供诊断，但不可塞进交付给图像模型的正向段落。

**例：**同为换脸+换装，当用户强调“人脸必须像图2”时，开场之后先放图2人物身份句群，随后商品句群；当用户强调“图3商品印花与工艺绝对准确”时，开场之后先放图3商品句群，人物身份句群其次。两次复用相同标准句，主要变化是句群次序和真实变量。

### 母版变量填充规则

母版中用「」标记的字段是变量。填充时去掉「」。除非用户明确要求，否则：

- 只有一个确定目标时，不写“居中/偏左/偏右随机变化”等互斥选项。
- “保持不变”与“允许变化”不能同时指向同一属性。
- 换背景不默认重新构图；换机位不默认保持背景像素原样。
- 局部修图不注入与任务无关的脸部、姿势、商业大片提示词。
- 童装按图片中可见的年龄阶段处理身体比例，不能默认套成人“八头身、165cm、瘦长腿”。
- 商品真实颜色、印花和结构默认比抽象“调性高级”更重要。

## 3. 固定辅助句（按条件启用；兼容部分原样复用，冲突时最小裁剪）

下面辅助句是候选固定句群，须先通过第 1D 节筛选后按本轮优先级插入，每组最多一次。无触发不添加；混有“不要/不得”的句子按原子约束拆分，兼容的正向句保留、禁用项归入【负面约束】，不能为了逐字保留而输出重复或矛盾要求。

**A01｜人物身份纯净（换脸自动启用）**

图中最终人物必须明显保留身份参考图的人物辨识度；不得混入底图原人物的五官特征，不得平均化、陌生化或重新设计五官。

**A02｜新脸光影融合（换脸自动启用）**

根据底图原有的主光方向、明暗分布、色温和环境反射，重新建立新面部受光；统一面部、脖颈与身体的肤色及阴影过渡，避免贴脸和拼接感。

**A03｜哑光自然肤质（用户说油腻/肤质假时启用；换脸默认可启用）**

面部保持柔和自然的哑光肤质，保留适度真实皮肤微纹理；高光克制，明暗过渡细腻，不要油腻、塑料感、蜡感、过度磨皮或泛白。

**A04｜比例守护（换脸、换姿势、换机位、人景融合自动启用）**

保持符合人物年龄阶段的人体比例，头部大小与肩颈、躯干协调；不要头部放大、脖颈缩短、肢体失真。若用户明确要求缩小头部约10%，追加：仅修正头部视觉比例，约缩小10%，不改变人物身份和五官结构。

**A05｜产品准确（商品替换、工艺修改自动启用；所有涉及服装的任务均先内部核查 Product Schema）**

保持商品参考图的版型轮廓、真实颜色、面料纹理、印花位置及关键结构，不重新设计商品，不增加或删除无关单品。

**A06｜姿势图隔离（P06 自动启用）**

姿势参考图仅负责骨架、关节角度与身体重心；不继承其人物身份、五官、服装、场景、材质、光影或视觉风格。

**A07｜场景空间融合（P04 自动启用）**

依据目标场景匹配人物尺度、机位高度、地平线和透视关系；重建接地阴影、环境反射与色温影响，避免悬浮、贴纸感和错误空间比例。

**A11｜参考场景光影读取（P04 必须先执行；P08 实际借用参考场景光照或 P10 使用光照参考时启用）**

这是一个**先观察、后填充**的标准句群，不是无条件猜光源。先从可见背景提取：①主光大致方位（以观者看画面的左/右/前/后/上方描述，不使用含混的“人物左侧”）；②光质类型（硬直射 / 柔和漫射 / 混合光，仅按可见阴影和高光判断）；③阴影朝向与边缘软硬；④明显可见时的色温与环境反射。只有确有视觉依据时才写“窗边自然光、直射日光、棚拍软箱”等物理来源，不假定隐藏灯具、具体布光器材、精确角度或色温数值。

**固定输出句式（用真实观察值填入，未观察到的子句整段省略）：**

参考场景「场景图」中，可见主光大致来自画面「主光方位」，呈「光质类型」，背景阴影「阴影方向与软硬特征」，整体光色「可观察色温或环境反射」。将这一光照关系延续到人物面部、颈部、身体及服装，依照人物朝向建立对应的受光面、阴影面与接地阴影，保持场景与人物属于同一光场。

如果只可判断光质而无法判断方向，则仅写可见光质与阴影，不强加光源方位；如果光照方向和类型均无法可靠判断，则不虚构观察结论，改用原 P04 通用光影融合句。不可把“从画面左上受光”误表述成“光从人物自身左侧来”。

**A12｜真透明 Alpha（P14A/B/C 自动启用）**

输出真实透明 PNG，指定目标之外的像素 Alpha=0；不要白底、黑底或棋盘格伪透明，不将背景颜色烘焙在主体半透明边缘。PNG 后缀不保证真实透明，只有验证实际 RGBA/Alpha 通道才可声称文件真透明；提示词本身只能提出要求。

**A13｜边缘保真（P14A/B/C 自动启用）**

轮廓完整、干净，无白黑边、杂色溢出或硬锯齿；发丝、毛绒、半透明纱和精细边缘保留自然半透明 Alpha；不磨掉真实织物、印花、缝线等商品信息。

**A14｜保留可见部分并仅补全必要缺口（P14A/B/C 按需启用）**

锁定原图已可见主体的身份、商品、姿态/形态、比例和相对位置，只补全为独立素材所必需的被遮挡或裁断部分；不重新摆姿势、换角度、改款或加配件。无法从参考确认的隐藏图案/文字不谎称能精确复原。原画幅与完整性冲突时保留画幅并允许主体 bbox 最小幅度扩展，不为了精确 bbox 硬裁断鞋底和肢体。

**A15｜指定图层隔离（P14A/B/C 自动启用）**

当前透明资产只包含用户指定主体及其真实组成；无关背景、家具、墙面、绿植、其他人、道具、文字或环境阴影等不混入。被用户指定为目标组成的服装、鞋、手持物、商品印花、标题字形或装饰须保留；不机械把一切物品都删除。

**A08｜新机位视差（P07 自动启用）**

背景需根据新机位重建遮挡关系、视差和透视变化；不得只是平面平移、镜像或拉伸原背景。

**A09｜局部修改边界（P03 / P09 自动启用）**

仅修改指定区域，未指定区域保持原有结构、颜色、材质、褶皱、构图和光影关系。

**A10｜保留光场清理（P11 自动启用）**

只清理噪点、杂色、压缩伪影和不稳定纹理；保留原图人物身份、商品结构、亮度、饱和度以及主光与阴影关系，不进行重打光。

### P14｜透明资产提取 / 补全重构（任务族）

按最终要成为**独立透明层的对象**选择子母版：人物 P14A、服装/商品 P14B、海报图文装饰元素 P14C。不能只因为出现“去背景”就调用 P04 换场景，也不能把 P14 当作重新摄影或自由重设计。

先识别修复对象：数字噪点、色噪、压缩伪影及 AI 不稳定细节可以清理；面料织纹、真实毛孔、真实印花和缝线不是应清除的“噪点”。保持 A10 的原光场、色彩和商品结构要求。

| C1 轻度（默认） | 高清、轻微清理、用户未指定强度 | clean refined image, stabilize noisy details, preserve original lighting and shadow structure；保留真实皮肤及面料微纹理 |

## 5. 框架外内容与填充规则

### 5.1 已知意图固定，未知内容自由扩写

按以下规则判断是否“框架外”：

- **已有案例 / 已有任务字段**：从母版和辅助句中筛选兼容句群，先执行第 1D 节。无冲突句群优先原文复用，不得为了“逐字复用”保留不适用、重复或互斥的句子。
- **已有任务 + 新增特殊要求**：保留已有母版核心句，新增约束作为独立句群按本次优先级放入正向单段落（若为禁止项则归入负面约束）；不统一堆到末尾。
- **完全未覆盖的新任务**：不强行套用最近似的 Pxx，也不强制当作 P12 文生图。内部可以规划任务、图源、编辑、保留、融合、禁止项，但交付仍使用四栏及按优先级组织的一段式正向提示词；遵守最小修改、图源隔离与不编造信息。
- **新任务反复出现**：可建议后续沉淀新 Pxx 母版；未得到用户要求前不要在调用中自行改写 GitHub Skill，也不暗称新母版已存在。

稳定的是已固化的任务表达，而不是禁止拓展新能力。

### 5.2 填充与省略：防止母版里留下占位符

每次输出前进行下面的检查：

1. 将所有「」变量替换为具体输入；绝不把变量占位符交给图像模型。
2. 未指定「数量」时默认 1 张；未指定真实参考图不得编造。
3. 未指定“发型继承要求”时默认跟随身份图发型；若只换五官、保留底图发型则按用户明确要求。
4. 不适用的可选句删除；**所有母版内部章节标题都不得出现在正向提示词中**。不得为了凑字数添加“无、无要求、可自行发挥”等模型可误解的内容。
5. 未提供的镜头角度、尺寸、身高、灯光不擅自写数值。
6. P09 没有工艺参考图时以文字工艺目标填充，不杜撰第二张图。
7. 每个辅助句群至多一次；母版与辅助句重复时保留更具体且来源明确的版本。逐属性执行第 1D 节的冲突检查及最小裁剪，不为改写而改写。
8. 正向段落按本轮优先级组织，禁止项汇集于独立【负面约束】；不禁止 EDIT 和必要 ADAPT，不重复整份清单。场景融合先观察背景再写有依据的 A11 光场描述。
9. 涉及商品先核查 Product Schema；清理修复先选 C1/C2/C3。完整成片检查第 1C 节三轴控制；透明资产按 P14A/B/C 与 A12–A15 路由。
10. 不把 A/B 测试、实验编号、版本历史或测试结论写入最终提示词。

## 6. 用户反馈后的定向修复

如果用户说“脸不像”：使用同一母版 P01/P13，不换新模板，只加强身份图信息与 A01，不叠加新摄影风格。

“脸油”：只调用 A03，不随机加入胶片颗粒、增加锐化或整体提亮。

“头太大”：只细化 A04，不擅自改身高和腿长。

“人物像贴进去”：仅加强 A07 和光影匹配，不自行重换场景。

“背景没跟着机位变”：强化 A08，并再次明确新机位；不把主体旋转偷换成相机移动。

“白模污染人物”：强化 A06，不改变商品提示词。

“工艺改多了”：强化 A09 与 P09 指定区域，不重画衣服。

“清噪后蜡化”：按第 4A 节降低修复强度，保留皮肤及面料必要微纹理；不要加入更多 ultra aggressive 同义词。
