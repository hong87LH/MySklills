# Ecom Image Prompt Director — Test Matrix v0.1

目标：验证 Skill 在真实电商生图工作中，是否能正确理解参考图职责，并通过 LOCK / EDIT / ADAPT 减少误改。

建议测试时使用 Debug / Test Mode。

## 评分维度

每个 Case 建议记录：

- Skill 判断质量：1–5
- Prompt 可执行性：1–5
- 实际生成结果：1–5
- 是否发生多余修改：是 / 否
- 最大失败点
- 下一版规则修正

## 第一轮核心测试

| ID | 任务 | 输入 | Skill 预期行为 | 重点检查 | 通过标准 |
|---|---|---|---|---|---|
| T01 | 单纯换脸 | 图1底图 + 图2人物 | 图1负责动作/衣服/场景/光线，图2负责身份 | 原脸残留、五官融合、受光 | 新脸辨识度高，底图其他内容基本不变 |
| T02 | 换脸 + 去油 | 图1 + 图2 + “不要油腻” | Identity + Lighting + Skin Finish | 鼻梁/额头/脸颊高光、蜡感 | 肤质哑光柔和，五官仍清楚 |

| T05 | 局部换装 | 图1 + 图2上衣 | 只 EDIT 上装，其他全部 LOCK | 下装/鞋/脸/场景是否被带改 | 非编辑区域基本不变 |

| T10 | 人景融合 | 人物图 + 场景图 | Scene Fit + Lighting | 人物尺度、透视、接地阴影、色温 | 人物不悬浮、不像抠图贴入 |
| T11 | 借构图 | 主体图 + 构图参考 | 只继承机位/占比/留白/空间关系 | 是否误抄人物和商品 | 构图相似但内容身份正确 |
| T12 | 光影统一 | 主体图 + 光影参考 | 只迁移光照逻辑 | 商品颜色、脸和结构 | 光影统一，主体没有被重新设计 |
| T13 | 清噪修复 | 已生成成片 | Cleanup & Repair | 噪点、偏色、过锐、光影变化 | 更干净但不重打光、不蜡化 |
| T14 | 换脸 + 换装 | 图1 + 图2脸 + 图3衣服 | 分离 Identity / Garment 职责 | 两张参考是否互相污染 | 人物和商品来源清晰 |
| T15 | 换脸 + 换姿势 + 换机位 | 多参考 + 文字 | 拆解复合任务并给出优先级 | 身份、比例、商品、空间是否同时失控 | Skill 输出结构清楚，并对高风险点给出提醒 |

## A/B 测试建议

每个 Case 尽量保留同一组输入图，并生成两版：

- A：当前日常原提示词
- B：Skill 优化后的提示词

建议对比：

1. 身份一致性
2. 商品结构准确性
3. 非编辑区域保持度
4. 人体比例
5. 光影融合
6. 场景透视
7. 肤质
8. 噪点 / 偏色
9. 是否需要二次修图
10. 生成成功率
