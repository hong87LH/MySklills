# Ecom Image Prompt Director v3.1

面向服装电商 AI 生图 / 修图的提示词编译 Skill：依据每次需求和真实参考图分工，优先调用已沉淀的固定句群，输出可复制的正向及负面约束。本 Skill 不直接生成图像。

## v3 核心：四栏固定，正向段落按当次优先级组织

### 外层展示始终四栏

1. 【任务理解】：简洁说明本轮真正要完成什么、强调什么。
2. 【参考图分工】：逐图交代底图、身份、商品、姿势、工艺或场景的来源与隔离范围。
3. 【最终提示词】：**一个独立代码块、一整段连续中文自然语言**。段内具有充分图源引用、编辑与保留边界、融合和成片要求；不再出现“【优先级】/【人物锁定】/【光影融合】”等内部栏目。
4. 【负面约束】：另一个独立代码块，首句统一为「负面约束：禁止……」，根据本次锁定与编辑边界逐项描述，不机械复制「不要……」清单；按模型是否支持独立负面参数决定实际输入方式。

### 内部编译流程

任务识别 → 图源职责 → 本轮实际优先级 → 选用固定母版/辅助句 → 必要变量填充 → **按优先级调整句群顺序** → 正向一段 + 负面一段。

**用户要求决定顺序，固定标准句保证表述稳定。**

- 相同任务、参考图分工、优先级与变量：尽量保持同样句群顺序和措辞。
- 同一种复合任务，人物辨识度优先时：开场之后优先表述身份来源、五官锁定，再表述服装。
- 同一种复合任务，服装工艺优先时：开场之后优先表述商品来源、印花走线与结构，再表述人物身份。
- 用户明确“只改某个区域”时：修改边界与未标注区域保留要求靠前且紧邻。
- 框架以外的特殊要求可以补写，按本次优先级插入，不机械堆在末尾。
- 正向段落必须独立成立：仅复制它也能理解图号职责。
- 不把内部 Pxx/Axx 编号、优先级策略行、LOCK/EDIT/ADAPT 过程或测试说明写入最终 Prompt。

## v3 场景融合补强：先读背景光影，再写控制句

人景融合 P04 默认调用 A11“参考场景光影读取”：

- 有依据地提取背景的主光大致方位（画面左/右/前/后/上）、光质（硬直射 / 柔和漫射 / 混合）、可见阴影方向及软硬程度，以及明显的色温或环境反射。
- 在【最终提示词】的一整段中用自然语言具体写出这些观察，再要求人物脸部、脖颈、服装和接地阴影匹配同一光场。
- 无法判断时不要猜测隐藏光源、精确角度、灯具型号或色温数值；只写可观察的特征。
- P08 仅在确实借鉴场景光照时使用，不因“借构图”自动继承整张参考图的光照；P10 纯校色时不强加光源方向。

## v3 保留并恢复的 v1 核心能力

v3 不只是固定 Prompt 的句式，也恢复了必要的内部判断与电商商品保护：

- **任务分析管线**：Task → Reference Roles → Priority → LOCK / EDIT / ADAPT → 能力路由 → 正向/负面编译。普通调用隐藏分析，只输出四栏。
- **Product Schema**：对涉及服装的任务检查 Category、Silhouette、Construction、Material、Color、Pattern/Print、Craft、Fit 八类属性；只写可见或用户提供的信息，不机械把八字段全部塞入 Prompt。
- **清理词资产**：v1 长版英文高清清理词逐字保留在 SKILL.md 内部，按 C1 默认轻度、C2 加强、C3 显式极强需求调用；避免误清真实面料织纹、印花、缝线和皮肤微纹理。
- **按需诊断**：只有用户提出“测试模式 / 调试模式 / 展开分析”等要求，才在【任务理解】一栏内追加简洁的任务分类、优先级、LOCK/EDIT/ADAPT 与模块说明；仍保留四栏和一个连续段落的正向 Prompt。

测试矩阵仍只存在历史归档，生产目录不放测试文件。

## v3.1 新增：三种透明素材任务

- **P14A 人物透明素材**：提取模特、锁定脸和服装与原姿势，补全必要肢体和鞋底，不混入背景。
- **P14B 商品透明素材**：提取服装/鞋/包等商品，保护 Product Schema 八字段，仅补必要轮廓，不误提模特/衣架等。
- **P14C 海报元素透明素材**：提取标题、前景、装饰或指定元素组；保留原尺寸位置与字形，禁止图层串层。

共用 A12 真 Alpha、A13 边缘保真、A14 必要补全、A15 指定层隔离。 bbox 为原图画幅的相对范围；遇到补全与 bbox 冲突时，以主体轮廓完整及原画幅保持为先。PNG 文件真正透明需要校验 RGBA / Alpha 通道，不能只凭提示词承诺生成成功。

## 完整成片中的姿势、构图与机位

当前 v3.1 将三者作为独立控制轴：

- **姿势**：已有图明确要换动作→P05；白模/姿势参考→P06+A06；全新有人物商业拍摄→P12 根据用户目标指定。
- **构图**：明确景别、画幅、留白、主体位置或借构图→P08/P12；已有图仅局部修图则保持原构图。
- **机位**：明确正/侧/后侧、俯仰、移动镜头或新视角→P07+A08；P12 全新拍摄才采用适宜商品展示的常规机位。

不能把人物转身当相机移动；没有明确授权，不在换脸、换装、工艺修图、透明提取中擅自变换三轴。
