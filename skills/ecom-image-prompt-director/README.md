# Ecom Image Prompt Director v3.0

面向服装电商 AI 生图 / 修图的提示词编译 Skill：依据每次需求和真实参考图分工，优先调用已沉淀的固定句群，输出可复制的正向及负面提示词。本 Skill 不直接生成图像。

## v3 核心：四栏固定，正向段落按当次优先级组织

### 外层展示始终四栏

1. 【任务理解】：简洁说明本轮真正要完成什么、强调什么。
2. 【参考图分工】：逐图交代底图、身份、商品、姿势、工艺或场景的来源与隔离范围。
3. 【最终提示词】：**一个独立代码块、一整段连续中文自然语言**。段内具有充分图源引用、编辑与保留边界、融合和成片要求；不再出现“【优先级】/【人物锁定】/【光影融合】”等内部栏目。
4. 【负面提示词】：另一个独立代码块，放本次相关禁止项；按目标模型是否支持独立负面参数决定实际输入方式。

### 内部编译流程

任务识别 → 图源职责 → 本轮实际优先级 → 选用固定母版/辅助句 → 必要变量填充 → **按优先级调整句群顺序** → 正向一段 + 负面一段。

**用户要求决定顺序，固定标准句保证表述稳定。**

- 相同任务、参考图分工、优先级与变量：尽量保持同样句群顺序和措辞。
- 同一种复合任务，人物辨识度优先时：开场之后优先表述身份来源、五官锁定，再表述服装。
- 同一种复合任务，服装工艺优先时：开场之后优先表述商品来源、印花走线与结构，再表述人物身份。
- 用户明确“只改某个区域”时：修改边界与未标注区域保留要求靠前且紧邻。
- 框架以外的特殊要求可以补写，按本次优先级插入，不机械堆在末尾。
- 正向段落必须独立成立：仅复制它也能理解图号职责。
- 不把内部 Pxx/Axx 编号、优先级策略行、LOCK/EDIT/ADAPT 过程或测试说明写入最终 Prompt。

## v3 场景融合补强：先读背景光影，再写控制句

人景融合 P04 默认调用 A11“参考场景光影读取”：

- 有依据地提取背景的主光大致方位（画面左/右/前/后/上）、光质（硬直射 / 柔和漫射 / 混合）、可见阴影方向及软硬程度，以及明显的色温或环境反射。
- 在【最终提示词】的一整段中用自然语言具体写出这些观察，再要求人物脸部、脖颈、服装和接地阴影匹配同一光场。
- 无法判断时不要猜测隐藏光源、精确角度、灯具型号或色温数值；只写可观察的特征。
- P08 仅在确实借鉴场景光照时使用，不因“借构图”自动继承整张参考图的光照；P10 纯校色时不强加光源方向。
