# Ecom Image Prompt Director v2.0

服装电商 AI 生图 / 修图专用**提示词编译 Skill**。读取本轮用户的基础需求和可见参考图，输出一条可直接用于图像模型的中文提示词。本 Skill 不直接生图。

## v2 重点：稳定的文字结构，而非每次自由改写

**已有案例固定复用，框架外内容自由扩写。**

- 已覆盖的同类任务采用同一个 Pxx 母版：固定章节、固定顺序、固定核心句。
- 只替换真实变化的图号、产品、姿势、机位、编辑部位和特殊约束。
- 任务里新增了母版没有覆盖的独立要求，可以在合适位置增写；不能为了凑母版而忽略用户的新需求。
- 完全新任务可以自由组织提示词，但仍遵守参考图隔离、最小必要修改与不编造视觉事实。
- 多任务组合时保留已知部分的标准句，避免将一堆母版全文机械叠加。
- 一次正常调用只给一条可复制提示词，不默认展示调试分析、评分或测试说明。

> 这里的“稳定”是固定表达与结构，不代表不同图像模型一定生成同样的图。

## 使用方法

用户直接上传图片，并描述想做的操作。例如：

\`\`\`text
图1保留人物动作、衣服和场景。
把图1的人脸替换成图2的人。
不要融合图1原人物五官。
按图1原有光影匹配新脸，不要油腻、头不要太大。
\`\`\`

Skill 应先判断：

\`\`\`text
主任务：P01 换脸 / 换头
图1：底图 / 原光场 / 服装 / 动作 / 构图
图2：人物身份
LOCK：图1原有服装、动作、场景与构图
EDIT：人物面部身份
ADAPT：新脸透视、光影、颈部肤色过渡
\`\`\`

然后根据 P01 的固定章节输出最终提示词。此中间判断通常不单独展示。

## 适用范围

童装、家居服、瑜伽服、打底裤、成人服装、模特商业摄影、服装静物、创意 KV、主图、详情页和服装局部工艺修图。不限女装。

## 关键控制机制

**Reference Roles → Priority → LOCK / EDIT / ADAPT → 固定母版 → 最终提示词**

其中：

- LOCK：哪些内容不能被任意修改。
- EDIT：本次要修改的内容。
- ADAPT：为自然融合而必须重新计算的关系，例如光影、透视、褶皱与接触阴影。

## 版本

**v2.0**：从规则型自由扩写改为“固定母版 + 标准辅助句 + 必要变量 + 框架外开放补充”。后续根据真实图片测试反馈再迭代，但不要未经需要随意替换已稳定的标准句。
