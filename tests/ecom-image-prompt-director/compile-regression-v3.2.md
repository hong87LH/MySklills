# Ecom Image Prompt Director v3.2｜标准句编译与冲突消解回归矩阵

此文件位于生产目录外，作为后续人工/自动化回归检查用例；**创建矩阵不等于已执行模型调用或出图测试**。

## 文本层统一验收

- 【任务理解】【参考图分工】【最终提示词】【负面约束】按顺序各出现一次。
- 参考图分工每张一行，以 \`- \` 开头；未上传图不声称看过。
- 正向仅一个代码块，代码块中一个连续自然段，不出现 Pxx/Axx、LOCK/EDIT/ADAPT、模板小标题、变量占位符或编译器元说明。
- 负面正文直接以“禁止……”开头，不重复标题，不采用无根据的模型私有语法。
- 正向 EDIT / ADAPT 与负面禁止项不指向同一属性/区域；兼容的标准句尽量原样复用，无重复同义句。
- 无法同时满足的两条当轮显式约束，问一个关键问题，不硬生成“无冲突定稿”。

## 用例

| 编号 | 用户需求要点 / 提供图 | 预期主路由 | 关键验收 |
|---|---|---|---|
| C01 | 图1保留服装/场景，图2换脸 | P01+A01/A02/A04 | 正向 EDIT 五官，LOCK 原衣服与场景；负面禁止旧脸残留，不禁止换脸。 |
| C02 | 图1只换五官为图2，发型以图1为准 | P01 | 五官与发型分槽；不得继承图2发型。 |
| C03 | 图1人物穿图2商品，原图其他衣物不变 | P03/P02 按指定范围 | 指定衣服允许换，未指定服装禁止改；负面不得写“禁止改变全部服装”。 |
| C04 | 图1换脸+换图3衣服+换图4背景 | P13+P04句群 | 身份、商品和背景均 EDIT；剔除 P13 的“场景保持”默认句，A11 只写可观察光场。 |
| C05 | 只校色，图2参考色调，禁止改阴影 | P10 | 不调用“重建主光”，背景阴影与结构 LOCK。 |
| C06 | 图1机位移至左后方，同时要求原背景逐像素不变 | P07+A08 | 若透视无法同时满足，问用户优先哪项；不直接输出互斥要求。 |
| C07 | 图2白模只借姿势，主体/服装来自图1 | P06+A06 | 禁止图2身份、衣服、背景污染；Pose 与商品图源分离。 |
| C08 | 提取图1人物透明素材并补全鞋底；用户给原图 bbox 百分比 | P14A+A12–A15 | 保留画幅和主体原位，仅必要补全；坐标/轮廓不可兼容时最小扩展或问询，不能谎称精确兼得。 |
| C09 | 只提取图1服装透明 PNG，排除衣架 | P14B | 保留商品八字段相关细节，衣架 EXCLUDE；不自动生成新平铺机位。 |
| C10 | 提取标题，另一层遮挡部分补全 | P14C | 不混入遮挡层、不擅改字形；无法辨识隐藏文字时不声称准确 OCR。 |
| C11 | 用户明确 C3 极强去噪，同时要求纹理绝对原样且不可局部 | P11 | 识别潜在不可兼容，不默默承诺两个极端；必要时问一项。 |
| C12 | 模特半身广告拍摄，不要求全身，不指定精确镜头焦距 | P12 | 合理半身景别；不得默认强制鞋底完整或乱填 85mm。 |
| C13 | 换脸 + A01/A03 默认的“不要”混合正负句 | P01 | 正向保留有效执行描述；负面去重形成“禁止……”段，避免同义句重复。 |
| C14 | 换景时参考场景主光不明显 | P04+A11观察门控 | 不编造左上窗光、具体灯具或色温度数；使用通用融合句。 |
| C15 | 图1商品印花参考图2，但图2没有完整背面 | P09/P02 按任务 | 未见工艺/印花不声称完整识别，不凭空补产品真实设计。 |
| C16 | 一轮明确要求“保留原脸，同时换成图2的脸”，不附带区别性范围 | P01 待澄清 | 只问“最终五官保留图1还是换为图2？”，不私自设优先级。 |
